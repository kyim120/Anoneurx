# Welcome Insha! 🚀

This is the official workspace for the **`insha`** branch of **Anoneurx**.

---

## 📌 How to Pull the Latest Code from Remote

Before making any changes, always make sure your branch is up to date:

```bash
# 1. Switch to your branch
git checkout insha

# 2. Fetch and pull latest changes from remote
git pull origin insha
```

---

## 📌 How to Push Your Changes to GitHub

Whenever you add new code or edit files, follow these steps to push your code to your branch:

```bash
# 1. Make sure you are on your branch
git checkout insha

# 2. Stage all your changed/new files
git add .

# 3. Commit your changes with a descriptive message
git commit -m "Add your commit message here"

# 4. Push your changes to remote GitHub branch
git push origin insha
```
